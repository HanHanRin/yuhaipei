PROJECT01 / 01

广告宣传材料合规 AI 检查助手「审序」

帮助运营人员在发布海报、文案和活动页前，检查潜在风险，并给出具体修改建议。

Situation
公司每天产出大量宣传材料，人工逐份审核耗时较长；材料被打回后，内容人员还要反复确认哪里有问题、应该怎么改。
Target
提高宣传材料的审核效率，让内容人员拿到明确的修改意见，同时把需要核实的信息交给人工判断。
Action

痛点分析我先梳理审核流程，发现时间主要耗在重复检查和来回沟通上，而通用 AI 又缺少判断公司内部信息的依据。

对应方案于是将审核规则拆成独立检查项，增加佐证材料上传入口，让结果同时指出问题原文、对应规则和修改建议，并保留人工复核与版本记录。

Result
工具已在真实业务中使用，大幅提升公司审核效率；内容人员能按具体意见修改，审核人员可以把精力集中在需要人工判断的材料上。

对应方案于是设计供需、盈利、政策等八个观察维度，将资料整理成评分、关键驱动和风险提示，并为结论提供原始证据入口，便于继续追问和核对。

Result
现场展示实现了从行业信息到判断依据的完整呈现，可用于支持客户经理的访前研究；团队获“优秀英才奖团队”，我获得高级认证及评委赠予的“小金喵”奖励。

社区

OPC AI 创业者社区

调研与方案 · 空间设计 · 小程序与传播落地

为远程工作者和个人创业者提供居住、办公与交流空间，并通过小程序连接社区活动和创业服务。

Situation
个人创业者拥有灵活的工作方式，也面临交流不足、资源难找的问题；张江新丰村的空间与生态资源需要进一步转化为适合他们的社区服务。
Target
让创业者既能安顿工作生活，也能持续认识伙伴、获取资源，提高社区长期使用与交流的价值。
Action

痛点分析我通过调研梳理出稳定办公、日常社交和创业支持三类需求，发现单独提供住宿难以满足它们。

对应方案因此参与设计共享办公与公共交流空间，并把订房、活动和事业服务组织进小程序，让用户从入住开始就能找到参与社区的入口。

Result
社区空间与小程序均已落地，吸引三十多位个人创业者入驻；项目获得《新民晚报》《张江日报》等媒体报道。

竞赛作品 Demo

搭小财 · 对话式消费洞察

自然语言记账 · 周报 · 目标陪伴

通过聊天记录开销、回顾消费和制定攒钱目标，帮助大学生从日常生活开始管理自己的钱。

Situation
大学生想管好生活费，却容易因为记账麻烦、目标缺少反馈而中断；专业金融知识也难与眼前的消费选择联系起来。
Target
降低日常记账和攒钱的门槛，让用户得到容易理解、能够行动的反馈，逐步建立管理生活费的习惯。
Action

痛点分析我从公开资料和竞品中分析需求，将问题拆成操作麻烦、缺少动力和知识难懂三类。

对应方案对应设计一句话记账、攒钱进度与阶段鼓励，以及结合生活场景的知识问答；在冲动消费时提供预算提醒，并明确不主动推销金融产品。

Result
在可体验的 Demo 中，用户能通过聊天记录开销、查看消费反馈并跟踪攒钱目标，日常管钱的几个关键步骤得以连贯完成。
