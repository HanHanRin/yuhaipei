> 项目：招商银行第 10 季数字金融训练营 · 客户经理 AI 工作台（任务 2.2）｜时间：2026.06（约 36 小时高强度协作交付）
> 角色：小组长 + 任务 2.2 产品负责人（三人子任务：两位产品、一位研发）。荣誉：团队获「优秀英才奖团队」；个人获高级认证与评委特别奖「小金喵」。

## 行业景气度智能研究工具

- **S（情境）**：核心用户是银行对公客户经理。他们接触一家新企业时要迅速判断所在行业处于什么周期、风险和机会在哪，但未必熟悉每个细分行业，也没时间读大量报告。本人没有金融学习或实习背景，需要先从 ToB 产品视角反推使用者、使用场景与决策问题。
- **T（任务）**：设计一个行业景气度智能研究工具，让系统完成第一轮行业研究，输出结构化、可解释、能被复盘的景气度判断，并嵌入「获客—筛客—揽客—授信/审核」的对公作业链路。
- **A（行动）**：
  - 痛点拆解：带组把客户经理从接到企业名单到形成拜访观点的全过程拆开，归纳为看不全、读不完、说不清、难复盘四条。
  - 多源数据清单：按宏观、产业、供需、价格、企业经营、政策、舆情、资本市场等类别明确数据来源、更新时间、使用方式与权限边界。
  - Multi-Agent 研究链路：不同 Agent 分别承担问题拆解、资料检索、数据分析、趋势判断和报告整合，前一环节结构化结果作为后一环节输入；证据不足或来源冲突时触发补充检索，而不是硬生成看似完整的答案。明确「模型做判断、代码算分」的稳定性边界。
  - 八维评分体系：设计政策导向、供需格局、成本盈利、增长空间、竞争态势、公众舆论、创新现状、资本规模八个维度及评分说明，输出总体景气度、关键驱动、主要风险与客户沟通建议；0–100 分、50 为荣枯线；每个分值都关联原始指标或资料来源，可从结论回溯到证据。
  - 可信与可复盘：基于金融场景风险，把自定义权重收敛为四套权威权重预设（锚定宏观经济景气指数、PMI、克强指数、波特五力等），并记录调整原因；每次分析保存时间、数据版本、分维度得分和关键证据，支持历史快照与控制变量对比。
- **R（结果）**：在 36 小时内完成产品文档、交互原型、数据清单、Agent 提示词、文本打分 skill 和答辩材料，并顺利完成现场展示；八个维度评分均可点击回溯原始证据。团队获「优秀英才奖团队」，个人获训练营高级认证与评委特别奖「小金喵」。
- **补充（团队合作与核心贡献）**：作为小组长，把团队三个任务整合成「获客—筛客—揽客—审查」的对公业务全链路故事，统筹答辩 PPT 汇总与路演海报制作。任务 2.2 内部：本人定「用户要什么、怎么呈现」（功能设计、页面设计、可视化看板、景气度报告模板、文本打分 skill、可溯源等），金融系同学定「数据从哪来、可信不可信」，研发同学负责让 Agent 跑起来并做工程优化（如拆子 Agent 并行提速），通过数据清单文档对齐口径。隐性亮点：无金融背景下短时间完成对公客户经理场景、行业研判链路与多源数据口径拆解。
