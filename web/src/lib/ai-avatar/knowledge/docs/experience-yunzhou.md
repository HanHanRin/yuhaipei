# 云舟识景 / 街景语义智能分析平台 · STAR 细节

> 机构：上海同济城市规划设计研究院｜角色：AI 产品研究｜时间：2025.09–2026.01｜地点：上海
> 成果：论文《大模型赋能的街区尺度街景语义智能分析研究》，本人为第二作者（实习 mentor 为第一作者）。

## 云舟识景 · AI 街景语义智能分析平台

- **S（情境）**：传统城市更新/街道评估依赖现场踏勘，规划师要拍照、记录、分类，再把观察整理成报告——专业性强但耗时大，不同人员对同一地点的关注点和表达方式还不一致；公开街景数据更新滞后、视角单一，不适配街区尺度精细化诊断；通用视觉模型能识别道路、树木、车辆、建筑，却不理解市政设施完整度、街墙界面等规划专业概念；端到端直接生成又难以溯源和分环节优化。
- **T（任务）**：把规划师「实地踏勘—识别—统计—成文」的人工流程，重构为「图像识别—知识检索—报告生成」的三段式 AI 工作流，让街景图像转成规划人员可直接理解和使用的空间诊断。
- **A（行动）**：
  - 标准化踏勘处理：统一街景图片采集要求与分析记录模板，设计图片批量导入、自动编号、项目归档与结构化汇总，减少逐张命名、分类的机械工作。
  - 规划语义转换（要素体系 + 知识图谱）：牵头建立「分析维度—对象类别—具体要素」三级要素体系，并与技术团队协同引入规划知识图谱；视觉模型先识别客观对象，知识图谱再把结果映射为市政设施完整度、街墙界面、慢行安全等规划专业指标并判断规划问题。
  - 多模型分层协同：感知层用 SAM3 做像素级语义分割并提取绿视率、天空率、界面连续性等定量指标；理解层用 Qwen3-VLM 做开放视觉描述；推理层用 Qwen3-LLM 结合知识图谱检索，按「识别问题—关联视觉—诊断原因—提出建议」生成结构化 JSON 与报告。
  - 分层可溯源：把分析拆成图像证据、对象识别、规划指标、问题诊断、策略建议几层，每条结论都与图片位置、中间指标和知识规则绑定，出错时能判断问题来自视觉识别、指标转换、知识规则还是文本生成。
  - 报告自动生成：由结构化分析结果驱动，按现状证据、问题诊断、影响分析、规划建议的固定结构汇总多张图片，生成报告初稿与策略文本，规划师只需复核和调整，不再逐张复制、从头组织文字。
- **R（结果）**：平台作为规划院内部工具使用，以上海市松江区中山街道 SJLC09 地块城市更新项目、30 张高精度街景图完成案例验证，平台报告与现场踏勘专家结论符合度超过 85%，多项建议可直接纳入项目文本；流程效率大幅提升。成果沉淀为论文《大模型赋能的街区尺度街景语义智能分析研究》，本人为第二作者。
- **补充**：这个项目让我理解 AI 产品不能只追求生成效果，而要有知识边界、模型分工、结构化输出和业务验证闭环；不用单一多模态大模型端到端出报告，正是为了在规划这种高专业约束场景里降低幻觉、保证可解释和可归因。已知局限（如百余张图片分析耗时较长、建筑风格细分不足）是后续性能优化与样本补充的方向。
