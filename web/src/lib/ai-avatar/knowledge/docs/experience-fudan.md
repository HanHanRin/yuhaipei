# 复旦金融研究中心 · 数据分析实习 · STAR 细节

> 单位：复旦大学金融研究中心消费市场大数据实验室｜岗位：数据分析员 / 研究助理（兼职实习）｜时间：2025.09–2025.11｜地点：上海
> 定位：补充型经历，不抢 AI 产品主线，证明数据治理、结构化研究与汇报表达能力。

## 政府咨询与产业研究数据支持

- **S（情境）**：政府咨询与产业研究项目信息源杂、口径多、字段不统一、材料体量大（政策文件、产业资料、场馆信息、活动数据、长篇报告）。研究团队需要把这些原始材料整理成可分析、可汇报、可辅助决策的结构化资料。
- **T（任务）**：负责资料收集、数据清洗、指标整理、Coze 工作流辅助分析与汇报材料制作，支持政策评估、产业链分析、场馆数据库和规划 PPT 等成果。
- **A（行动）**：
  - 研究资料结构化：参与革命老区对口合作评估、沪明农文旅融合、沪明商业文化融合、松江区商贸服务业「十五五」规划等课题，用 IOPOI、SWOT、RMP、KPI 等框架辅助拆解研究目标、评价维度和报告结构。
  - 数据采集与标签治理：主导新能源、光伏、生物医药、数字经济等产业链关键词体系整理，按「上游—中游—下游」拆解产业环节，整理专利/软著关键词、经营范围关键词、行业分类与行业分级字段，支撑企业画像、产业检索与政策研究。
  - 数据库建设：主导上海赛娱场馆信息采集与清洗，基于高德地图 API 等数据源建立场馆名、区、地址、类型、座位数、规模等级、运营状态等字段口径。
  - 工具化与汇报：后期用 Coze 工作流辅助文本处理、数据分析和报告撰写；把 50+ 页松江区商贸服务业「十五五」规划报告提炼为 35 页汇报 PPT，形成「发展基础—挑战—机遇—目标—任务—保障」的展示结构。
- **R（结果）**：主导构建 370+ 场馆、3900+ 演出赛事项目记录的基础数据库；完成新能源/光伏/生物医药/数字经济等多行业产业链关键词标签体系；将长篇规划报告压缩为 35 页汇报 PPT，抽取商品销售额、社零、商业综合体、线上/直播经济等关键指标。
- **补充**：这段经历强化了字段口径、分类标准和数据可复用性意识，这些能力会迁移到 AI 产品的用户研究、指标看板、知识库治理与业务规则整理中。后期活动评估项目参与较少，只作为 Coze 工作流文本处理/数据分析/报告撰写的支持，不作主线成果。
