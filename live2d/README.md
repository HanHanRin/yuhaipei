# 奶龙网页桌宠

模型来源：项目根目录 `免费模型—奶蛙/`，保留原模型与贴图，按用户要求启用模型自带去水印参数 `ParamAngleX7 = 2`（对应 `去水印.exp3.json`）。网页资源使用英文文件名，原始目录不变。

- `naiwa/`：Cubism 模型、贴图、物理配置和参数说明；网页不使用 VTube Studio 的摄像头映射配置。
- `runtime/live2dcubismcore.min.js`：Live2D 官方 Cubism Core，来自 <https://cubism.live2d.com/sdk-web/cubismcore/live2dcubismcore.min.js>，文件内原有版权与许可说明保留。
- 前端组件：`web/src/components/ai-avatar/naiwa-pet.tsx`。

动作通过模型原生参数驱动：眼珠、头部与身体跟随鼠标，身体稍慢于头部，形成自然的转身与侧倾；定时眨眼、呼吸、聊天状态嘴部变化。触屏不跟随手指；遵循系统减少动态效果设置；页面隐藏时暂停渲染。加载失败时恢复原聊天入口形象。

互动入口在 `web/src/components/ai-avatar/pet-launcher.tsx`：

- 单击打开聊天；双击开心摇摆，避免同时误开聊天。
- 鼠标轻抚头部，奶龙眯眼、点头，并显示简短回应。
- 按住拖动可以移动桌宠，拖动结束后用原模型手部参数回应；菜单可回到右下角。
- 右键或长按奶龙打开玩法：摸头、喂食、开心摇摆、睡觉/叫醒、黑衣造型、位置复位。键盘可用 Shift + F10 打开菜单，Escape 关闭菜单。
- 45 秒无鼠标活动时，闲置状态自动打盹；再次移动鼠标唤醒。菜单手动睡觉可通过点击或互动叫醒。
- 黑衣和手部参数保留模型的原始默认值（本模型默认 `-1`），启用时采用原表达式的增量，避免将 `0` 误当作默认而显示中间造型。

依赖采用 `pixi.js@6.5.10` 和 `pixi-live2d-display@0.4.0`，运行时与模型均由网站本地提供，无需 VTube Studio。
